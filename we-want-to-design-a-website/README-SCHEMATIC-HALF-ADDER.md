# Schematic presentation update

The generated Logic Solver schematic now uses the same compact engineering presentation as the Circuit Lab reference schematics:

- explicit gate silhouettes for AND/OR/XOR/NAND/NOR/XNOR/NOT
- input labels and pin-aligned connections
- compact left-to-right gate columns
- Manhattan routing with dedicated lanes
- output wire and value marker kept close to the final gate
- HIGH-state glow and signal animation preserved
- zoom/pan retained, but the default viewport is compact

This intentionally avoids a generic graph/node-editor look.
